# НАСТРОЙ — демо-сайт

Одностраничный демо-сайт строительной компании «НАСТРОЙ» (г. Киров).

- Статика: HTML + CSS + JS, без сборки и зависимостей.
- Фото, тексты и контакты взяты из открытого сообщества ВКонтакте [vk.ru/nastroy43](https://vk.ru/nastroy43).
- Не является официальным сайтом; демонстрационный макет, заявки через него не собираются.

## Запуск

Открыть `index.html` в браузере, либо поднять любой статический сервер:

```
python -m http.server 8000
```
